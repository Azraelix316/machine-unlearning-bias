Bias Removal in LLMs via Machine UnlearningProject Intent & V2 GoalsThis repository contains the code and methodology for mitigating media bias in Large Language Models using post-hoc machine unlearning. The v2 upgrade scales the original proof-of-concept to modern, multi-GPU architectures (2B–70B parameters) and introduces enhanced evaluation metrics for text degeneration and sampling vulnerability.  Technical ProceduresLegacy V1 ProcedureModel & Architecture: Evaluated exclusively on a lightweight GPT-2 baseline (~124M parameters) running on a single CPU.  Data Processing: Curated 2,000 text samples (capped at 300 characters) from the C4 dataset, classified using DA-RoBERTa-BABE-ft to build a biased subset (~11% of collected data).  Training Protocol:Fine-tuned GPT-2 for 10 epochs on half of the biased dataset at a learning rate of $2 \times 10^{-5}$ to inject bias.  Executed unlearning for 10 epochs on the remaining disjoint half of the biased dataset using gradient ascent alongside anchor data to prevent catastrophic forgetting.  Evaluation Scope: Assessed outputs on 300 test prompts via DA-RoBERTa-BABE-ft scoring at a single generation temperature ($T = 0.8$).  New V2 ProcedureScaled Model Support: Extends evaluation across larger model families using 4-bit NF4 quantization (bitsandbytes) and dynamic device memory mapping (infer_auto_device_map) across 4 GPUs. Models include:  google/gemma-4-e2b  Qwen/Qwen3.8-27B  google/gemma-4-31B-it  google/gemma-4-26B-A4B-it  deepseek-ai/DeepSeek-R1-Distill-Qwen-70B  Data Pipeline: Scales C4 sample streaming to 20,000 entries and filters multimodal encoder layers during target module discovery.  QLoRA Unlearning Protocol:Applies peft target-module adapters ($r=16, \alpha=32$) with gradient checkpointing enabled.  Poison Step: Trains QLoRA adapters on biased_subset_A for 10 epochs ($LR = 2 \times 10^{-5}$) using mini-batches.  Unlearn Step: Minimizes a joint loss function combining gradient ascent on biased_subset_B and gradient descent on clean anchor data over 10 epochs:$$\mathcal{L}_{\text{total}} = 0.5 \times (-\mathcal{L}_{\text{forget}} + \mathcal{L}_{\text{anchor}})$$  Advanced Diagnostics:Degeneration Tracking: Calculates repeated trigram frequencies to ensure unlearning does not compromise generation quality.  Temperature Vulnerability Sweep: Tests adapter stability across sampling temperatures ($T \in [0.1, 1.9]$).
